문제

폐쇄망 연구기관에서는 외부 LLM 서비스 사용 불가. 문서 작성·데이터 정리·연구 보조처럼 반복되는 업무를 LLM으로 줄이려면, 내부 GPU에서 도는 모델과 실제 업무 형식(HWP·HWPX·DXF 등)에 맞춘 도구가 필요.

접근 — 포털

  • 단일 진입점. 모든 에이전트를 포털 아래 경로로 리버스 프록시(스트리밍 응답·파일 다운로드 포함). 사용자는 포트 하나만 열면 됨.
  • 찾고 실행하기. 검색·카테고리·인기 순위·노하우 피드, 에이전트별 시작/중지와 사용 설명 보기. 신규 에이전트 등록 화면 제공.
  • 운영. 공용 LLM 백엔드를 모든 에이전트에 연결, 데이터는 도구별 작업 폴더 한곳에 모아 백업 단순화. 표준 라이브러리만으로 구현해 폐쇄망 설치 부담 최소화.

접근 — 구축한 에이전트

  • 문서·사무.
    • HWP·PDF 요약·질의응답, 공문서 초안 HWPX 생성
    • 주간보고 개인 작성·실 단위 취합, HWPX·DOCX 출력
    • 업무 메일 작성·회신·윤문(수치 보존 검사), 축사·공지문 글쓰기, 한글 번역투 교정
    • 출처 기반 인용 채팅·노트 정리
  • 연구 보조.
    • 논문 투고 전 사전 심사 — 인용 확인된 지적·예상 질문 + 그림·수치·약어 점검
    • 단백질 구조 예측·결합 친화도 순위·서열 설계(Boltz-2 + ProteinMPNN)
    • 배터리 성능·열화 예측(PyBaMM), 방사선 차폐·선량 간이 계산
    • 그래프 이미지 → 수치 데이터, 표 → 편집 가능한 차트(XLSX·PPTX·DOCX·HWPX), 자연어 → SQL
  • 설계·시각화.
    • 말로 설명하면 3D 부품·2D 판재·배치도 생성, 기존 DXF 수정
    • 텍스트·손그림 → 논문 스타일 다이어그램
  • 음성·영상.
    • 녹음 → 화자 분리 → 회의록·인사이트
    • 한국어 음성 합성, 사진+음성 샘플 기반 립싱크 아바타

결과

외부망 없이 쓰는 업무·연구용 에이전트 20여 종을 하나의 포털로 통합. 에이전트를 추가해도 사용자 접속 경로는 그대로 유지되는 구조로 확장 중.

기술

Python · Ollama(GPU 서빙) · 리버스 프록시(SSE) · SQLite · HWPX/DOCX/DXF 생성 · Whisper STT · TTS · Boltz-2 · ProteinMPNN · PyBaMM.
